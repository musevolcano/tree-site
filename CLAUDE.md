# Big Creek Tree Service — Project Context
## What this is
Production website and lead-gen system for Big Creek Tree Service. Northeast Ohio, owned by Joseph (Acyuta's brother). Operating model: 10% commission to Muse Volcano on inbound leads.
## Goals
1. Be crawler-visible. Current Hostinger site is JS-rendered and invisible to Googlebot.
2. Rank locally for tree service queries within 40 miles of Cleveland.
3. Convert traffic to same-day estimate requests for B2B and residential.
4. B2B targets: property managers, HOAs, developers, insurance adjusters.
## Stack
- Next.js on Vercel (static export or ISR, never plain CSR)
- Tailwind CSS
- shadcn/ui where applicable
